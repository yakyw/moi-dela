# Мои дела — список задач

Адаптивное веб-приложение для ведения личного списка задач. Проект написан на чистом HTML, CSS и JavaScript — без сборщиков, фреймворков и внешних зависимостей.

## Возможности

- Добавление задач через кнопку или клавишу `Enter`.
- Отметка задач как выполненных и возврат в активные.
- Редактирование названия задачи прямо в списке (`Escape` отменяет редактирование).
- Удаление задачи с возможностью отменить действие.
- Фильтрация: все задачи, активные и выполненные.
- Очистка всех выполненных задач с возможностью отмены.
- Индикатор общего прогресса и счётчики.
- Автоматическое сохранение в `localStorage`.
- Синхронизация списка между открытыми вкладками одного браузера.
- Адаптивная вёрстка, управление с клавиатуры, подписи для скринридеров и поддержка `prefers-reduced-motion`.


## Хранение данных и ограничения

Задачи сохраняются в `localStorage` текущего браузера. Они не передаются на сервер, не синхронизируются между разными устройствами и не появятся в другом браузере. При очистке данных сайта браузером локальный список также может быть удалён.
